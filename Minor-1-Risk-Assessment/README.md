# Minor Project 1 — Cybersecurity Risk Assessment Framework for Small Businesses

## Objective

Develop a model for evaluating cybersecurity risks in small and medium enterprises (SMEs) and propose mitigation strategies to improve their security posture.

## Project Steps

1. Research common cybersecurity risks in SMEs.
2. Develop a risk assessment model.
3. Create a risk evaluation metric based on severity and impact.
4. Propose risk mitigation strategies.
5. Validate the model using case studies.
6. Document findings and provide cybersecurity best practices.
